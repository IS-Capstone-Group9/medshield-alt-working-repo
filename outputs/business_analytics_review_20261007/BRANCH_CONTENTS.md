# Review evidence included in medshield/vercel

This branch contains the reviewed application/parser fixes, regression tests,
canonical documentation, both corrected product-master CSV copies and concise
business analytics reports, QA results and source-bound receipts. It also keeps
the current-version-19 label aggregate extract and historical product-category
research seed used for the draft master.

Bulk full-row facts, per-record inspections, spreadsheet authoring matrices,
backup CSVs, unrelated browser results, temporary scripts and runtime dependencies
remain local. Historical receipts still identify their original source hashes;
their presence in this branch does not mean every referenced source archive is
included or that its checks can run without those separately retained inputs.

The application still reads Databricks. Pushing this branch does not publish the
local catalog to Databricks, approve products, activate models or establish a
configured Vercel deployment. See [the analytical assessment](REVIEW.md).
