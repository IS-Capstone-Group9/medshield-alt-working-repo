# Business Analysis Frameworks

Apply when relevant:

- Requirements Analysis: User Stories, Use Cases, Acceptance Criteria
- Business Analysis: SWOT, PESTLE, Root Cause Analysis, Gap Analysis
- Process Analysis: BPMN, SIPOC, Value Stream Mapping
- Decision Analysis: Decision Trees, Cost-Benefit Analysis
- Stakeholder Analysis: Power-Interest Matrix
- Risk Analysis: Risk Matrix
- Requirements Prioritization: MoSCoW, Kano Model
