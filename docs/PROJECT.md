# MedShield Project

MedShield Business Analytics is a capstone decision-support system for pharmaceutical sales, territory performance, product prioritization, and inventory planning.

## Current Stack

- Frontend: Next.js and TypeScript
- Backend: TypeScript API gateway in `backend/`
- Analytics: Python Flask services in `services/`
- Database: Supabase PostgreSQL warehouse schema

## Primary Objective

Provide a dashboard that is easy to run locally, grounded in warehouse-backed data, and clear enough to explain in the capstone report.
